FastAPI
Built a REST API using FastAPI.


Learned HTTP methods: GET, POST, PUT, DELETE.
Used APIRouter to organize endpoints.
Used Swagger (/docs) for API testing.


Pydantic
Validates incoming request data.
Converts JSON into Python objects.
Separate schemas for Create, Update, and Response.


CRUD
POST: Create and store an email.
GET: Retrieve all emails or one by ID.
PUT: Update an existing email.
DELETE: Remove an email.


REST Concepts
Path parameters identify resources (e.g., /emails/{id}).
Request body carries client data.
Response models define API output.
